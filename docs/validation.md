# v0.1.0 验证记录

测试环境为 Apple Silicon Mac、macOS 27.2.1、ONLYOFFICE Desktop Editors 10.0.0（564）和演示 SDK 10.0.0（169）。媒体样本是合成的测试画面和音频。

| 场景 | 验证结果 |
| --- | --- |
| Finder 直接拖放 | 中文及空格文件名的 MP4、MOV、MP3 插入当前幻灯片。单次多选拖放写入了三个媒体对象。 |
| 新建与已有 PPTX | 新建文件和已有多页文件均可插入媒体并保存到本地文件夹。 |
| 保存与重新打开 | PPTX 包内的媒体与源文件 SHA-256 一致。移走源媒体后，重开 PPTX 的放映模式可播放，捕获到 MP4、MOV、MP3 样本的测试音。 |
| 撤销与重做 | 保存后的 PPTX 在撤销时移除了目标页媒体引用，重做后恢复。 |
| 图片及文本拖放 | Finder PNG 与 TextEdit 选中文本通过实机测试。检查保存后的 PPTX，确认图片引用和拖入的文本都写进了目标页。 |
| 只读行为 | 只读文件的原件校验和不变，ONLYOFFICE 允许编辑副本。编辑器禁止修改时，自动化测试确认媒体桥接不会被调用。 |
| 构建与归档 | App 签名完整性校验通过。解压本地 App ZIP 后，补丁文件与实机使用的 App 一致。 |

运行 `node --test test/media-drop.test.mjs` 可复跑自动化测试。`test/verify-pptx-media.py` 可检查指定幻灯片的内部媒体引用及载荷。
